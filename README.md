# Evreni Bitiren Abi Sayacı

## Bilimsel Özet

Bu repository, modern fiziğin en büyük sorularından birine cevap aramaktadır:

**Kaç kere "abi" dersen evren çöker?**

Yıllar süren (yaklaşık 3 çay molası) titiz araştırmalar sonucunda, eşik değerinin **47** olduğu bilimsel olarak kanıtlanmıştır. Bu değer, kuantum mekaniği, Türk aile yapısı ve dayılarının otoritesi göz önüne alınarak hesaplanmıştır.

## Nasıl Çalışır?

1. Programı çalıştırın.
2. Bugün kaç kere "abi" dediğinizi girin.
3. Program son derece yavaş ve bilimsel bir şekilde hesaplar.
4. Eğer eşik aşılmışsa evren çöküş uyarısı alırsınız.
5. Eşik aşılmamışsa "güvende" olduğunuz bildirilir (bu da bilimsel bir yalandır).

## Kurulum

```bash
python3 abi_sayaci.py
```

Başka hiçbir şey gerekmez. Çay içmek tavsiye edilir ama zorunlu değildir.
